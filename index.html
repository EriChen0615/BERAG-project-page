OverviewAbstractResultsBibTeX

BERAG generates answers by combining document-conditioned predictions, updating each document’s weight as every token is generated. Bayesian Ensemble Fine-Tuning (BEFT) trains this ensemble end to end.

Abstract

Standard retrieval-augmented generation concatenates retrieved documents into one long context, making source attribution difficult and increasing computation and memory costs. Relevant evidence can also be overlooked because of its position in the context.

BERAG conditions the model on individual documents and combines their predictions using document posterior probabilities, updated token by token with Bayes’ rule. Together with BEFT, it supports deeper retrieval lists, explicit document attribution, and document pruning for faster decoding. Experiments cover knowledge-based VQA, document VQA, and multimodal needle-in-a-haystack tasks.
